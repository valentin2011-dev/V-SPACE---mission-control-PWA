# V SPACE — Mission Control

PWA statique prête pour GitHub Pages.

## Mise en ligne
1. Décompresser le ZIP.
2. Mettre `index.html`, `style.css`, `app.js`, `manifest.json` et le dossier `icons` dans le repository.
3. GitHub → Settings → Pages → Deploy from branch → `main` / `root`.
4. Ouvrir l'URL GitHub Pages sur iPhone et utiliser « Ajouter à l’écran d’accueil ».

## Contenu
- 3 véhicules : V-01, V-02, V-03
- 3 missions : Earth Orbit, Lunar Transfer, Mars Transfer
- Dashboard de télémétrie animé
- Trajectoire canvas
- moteurs / systèmes / alertes
- compte à rebours et phases de vol
- écran de résultat
- mode plein écran
- responsive portrait/paysage
- fonctionnement 100 % côté navigateur, sans serveur
